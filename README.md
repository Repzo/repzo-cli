# Repzo CLI

The official standalone command-line interface for Repzo Workstation and AI agents.

## Install

macOS, Linux, or WSL:

```bash
curl -fsSL https://workstation.repzo.com/install-cli | bash
```

Windows PowerShell:

```powershell
irm https://workstation.repzo.com/install-cli.ps1 | iex
```

Then authenticate with `repzo auth login`.

Release binaries are SHA-256 checksummed, Sigstore-signed, and built from the Repzo Workstation release workflow.

See [Releases](https://github.com/Repzo/repzo-cli/releases) for manual downloads.
